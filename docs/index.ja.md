# LiveCaption

会議にリアルタイムの字幕を出すシステムです。会議の音を聞き、文字に起こし、訳して、
字幕を必要とする参加者に見せます。

字幕の向きは会議ごとに選びます。**日本語の会議に英語字幕**、または
**英語の会議に日本語字幕**です。

## 必要なもの

Docker の動く Windows か Linux のマシンが1台、OpenAI の APIキー、Tailscale の
アカウント。**ノートPC 1台で足ります。** 自分は普段どおり会議に参加して発言し、
コンテナの中の Zoom が無言の参加者として同じ会議に入ります。

文字起こしの料金は、1時間の会議で約1ドルです。
